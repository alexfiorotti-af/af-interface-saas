# af-interface-saas

Skill da **AF Tecnologia e Marketing** para desenhar, redesenhar e revisar telas e a identidade
visual dos SaaS da casa (ClavusOS, CoachOS, Pousa, ORDO e os próximos nichos do construtor).

É só método: nada aqui executa código, chama a internet ou manda telemetria.

## O que tem

| Arquivo | Para quê |
|---|---|
| `SKILL.md` | as regras: navegação em um andar, sistema visual, white-label, proibidos, polimento, checagem final |
| `references/identidade-de-nicho.md` | o método para criar a marca de um nicho novo |
| `references/marca-clavusos.md` | o manual da marca ClavusOS "Cereja & Porcelana" |
| `references/tokens-clavusos.css` / `.json` | os tokens prontos para implementar |
| `references/auditoria-skills.md` | as skills públicas avaliadas, o que aproveitamos e o que evitar |

## Como usar

- **Claude (app):** salvar pelo card de proposta de skill, ou subir esta pasta em Configurações › Skills.
- **Claude Code:** clonar em `~/.claude/skills/af-interface-saas` (ou em `.claude/skills/` de um projeto).
- Pedir, por exemplo: "redesenha a tela de caixa no padrão af-interface-saas" ou "cria a identidade do próximo nicho com a af-interface-saas".
